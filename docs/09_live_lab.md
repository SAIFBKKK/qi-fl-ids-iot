# Live Lab

The live lab demonstrates how IoT/WSN traffic can flow through the deployment stack.

High-level flow:

```text
IoT node or replay source
  -> MQTT broker
  -> feature extraction
  -> IDS API
  -> dashboard and monitoring
```

Use placeholders in public documentation:

- `<SERVER_IP>`
- `<MQTT_HOST>`
- `<REPO_ROOT>`

Do not publish private lab IPs, credentials, packet captures, or terminal logs.

The live lab validates deployment flow and observability. It is not a new statistical evaluation of model accuracy.
