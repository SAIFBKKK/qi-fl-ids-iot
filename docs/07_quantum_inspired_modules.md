# Quantum-Inspired Modules

The project studies several quantum-inspired ideas for IDS and FL.

## QGA

QGA is the final validated quantum-inspired component. It selects a compact feature subset for the practical model.

Final selected path:

```text
FedAvg + QGA
12 QGA-selected features
```

## QIFA

QIFA is an adaptive aggregation research module. It is useful for comparison and analysis, but it is not the final selected deployment model.

## FedTN/MPS

FedTN/MPS is used for structural compression analysis. It is not full final FL training.

## QIARM

QIARM is not part of the final validated implementation.
