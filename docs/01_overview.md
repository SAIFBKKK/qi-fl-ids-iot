# Overview

QI-FL-IDS-IoT is a research framework for intrusion detection in IoT and wireless sensor networks.

Full title:

```text
Quantum-Inspired Federated Framework for Dynamic IoT Networks:
Intrusion Detection System for IoT/WSN Security
```

The framework combines:

- Federated Learning for privacy-preserving distributed IDS.
- QGA feature selection for compact and effective IDS input features.
- QIFA aggregation research.
- FedTN/MPS structural compression analysis.
- Docker, MQTT, IDS API, Prometheus, Grafana, and live-lab deployment flow.

The final selected practical model is **FedAvg + QGA** with **12 QGA-selected features**.
