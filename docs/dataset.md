# Dataset Package Notes

Kaggle dataset: `COMING_SOON`

The public GitHub repository does not contain the full processed dataset. The dataset package is planned for Kaggle after license and publication review.

Phase 3 local staging exists for the developer at:

```text
../qi-fl-ids-iot-kaggle-dataset/phase3_20260612_140955/
```

This path is not a public URL.

The staged package contains processed CICIoT2023-derived materials:

- balanced dataset files
- L1 binary preprocessed data
- L2 family preprocessed data
- federated partitions
- metadata
- manifests
- checksums

Users must cite CICIoT2023:

```text
Neto, E. C. P., Dadkhah, S., Ferreira, R., Zohourian, A.,
Lu, R., and Ghorbani, A. A. (2023).
CICIoT2023: A Real-Time Dataset and Benchmark for Large-Scale Attacks
in IoT Environments. Sensors, 23(13), 5941.
DOI: 10.3390/s23135941
```

The Kaggle license must be verified before upload.
