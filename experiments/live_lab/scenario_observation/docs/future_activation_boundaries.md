# Future Activation Boundaries

P16.11 does not activate scenarios.

## Required Before Future Activation

- Human review of the exact controlled observation design.
- Host-only network confirmed.
- No external network path in the demonstration window.
- VM1 and VM2 registration confirmed.
- Dashboard `/demo` ready.
- final-ids-api and final-mqtt-bridge error counters at zero before start.
- Evidence template prepared.

## Repository Boundary

The repository must not store executable offensive commands. Scientific tool names may appear only as references.

## Runtime Boundary

Future activation must remain inside the isolated live lab. It must not target external machines, broad networks, or unmanaged systems.

## Evidence Boundary

Every future observation should record:

- scenario label,
- target node,
- PacketWindow summary,
- feature mode,
- MQTT topics,
- prediction and alert evidence,
- runtime errors,
- limitations.
