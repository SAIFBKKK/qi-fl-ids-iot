# Safety Scope

P16.1 is preparation only.

Allowed:

- static files;
- dry-run scripts;
- controlled JSON payload construction;
- future passive packet-window extraction design;
- local isolated lab documentation.

Not allowed in this step:

- Docker startup;
- VM creation;
- live packet capture;
- active traffic generation;
- training;
- Flower runtime;
- modification of P8-P16 results.
