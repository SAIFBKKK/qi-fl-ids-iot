- Confirm branch `final/quantum-inspired-fl-iot-ids-final`.
- Confirm reports P16.1 audit and plan exist.
- Confirm `experiments/live_lab/` is clonable.
- Run node dry-runs for weak and medium nodes.

- Clone repo in VMs.
- Register nodes.
- Replay controlled feature payloads.
- Validate MQTT predictions and alerts.
- Capture screenshots and final evidence.
