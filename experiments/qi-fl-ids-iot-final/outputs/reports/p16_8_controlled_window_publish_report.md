# P16.8 Controlled Packet-Window MQTT Publish Report

## Objective

P16.8 validates that features generated by the P16.7 realtime agent can feed the MQTT-to-IDS path already proven in P16.6.

Target path:

`SyntheticPacketSource -> PacketWindow(30) -> 28 CICIoT2023-like features -> optional scaler -> optional QGA mask -> MQTT ids/flows/{node_id} -> final-mqtt-bridge -> final-ids-api -> ids/predictions/{node_id} -> ids/alerts/{node_id}`

## Difference Between P16.6, P16.7, And P16.8

- P16.6 validated controlled JSON payloads sent directly to MQTT.
- P16.7 built the packet-window feature extraction prototype in dry-run mode.
- P16.8 connects those two pieces by publishing controlled synthetic packet-window outputs to MQTT.

## Architecture Validated

- Source: `SyntheticPacketSource` only.
- Window: `PacketWindow(30)`.
- VM1 path: `PacketWindow(30) -> selected_12_scaled -> MQTT -> prediction/alert`.
- VM2 path: `PacketWindow(30) -> original_28_scaled -> MQTT -> final-ids-api QGA mask -> prediction/alert`.
- MQTT topics:
  - `ids/flows/iot-rpi-weak`
  - `ids/flows/iot-smart-watch-medium`
  - `ids/predictions/{node_id}`
  - `ids/alerts/{node_id}`

## Expected Metrics

- `final_mqtt_bridge_flows_received_total{node_id="iot-rpi-weak"}` increments after VM1 publish.
- `final_mqtt_bridge_predictions_published_total{node_id="iot-rpi-weak"}` increments after VM1 publish.
- `final_mqtt_bridge_alerts_published_total{node_id="iot-rpi-weak"}` increments if the prediction path emits an alert.
- `final_mqtt_bridge_flows_received_total{node_id="iot-smart-watch-medium"}` increments after VM2 publish.
- `final_mqtt_bridge_predictions_published_total{node_id="iot-smart-watch-medium"}` increments after VM2 publish.
- `final_mqtt_bridge_alerts_published_total{node_id="iot-smart-watch-medium"}` increments if the prediction path emits an alert.
- `final_ids_api_prediction_errors_total` remains `0`.
- `final_mqtt_bridge_prediction_errors_total` remains `0`.

## Limits

- Features are safe CICIoT2023-like approximations.
- This is not a scientific performance evaluation.
- No live capture is used.
- No Kali scenario is started.
- P16.8 does not modify model artifacts or P8-P16 results.
